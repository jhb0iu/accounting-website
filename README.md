# 简财云 — 让财务管理回归简单

个人财务与团队协作的一站式记账工具。

## 功能特性

- ✅ **清晰的分类管理** - 自定义收入和支出类别
- ✅ **智能预算控制** - 设定月度预算，实时跟踪消费进度
- ✅ **多维度报表分析** - 按时间、类别生成可视化图表
- ✅ **多人协作记账** - 创建团队，共享账单，AA制自动分摊
- ✅ **定时记录** - 固定账单设置自动记账
- ✅ **数据安全保障** - 本地存储，支持导出备份

## 快速开始

1. 访问 [仪表盘](/dashboard)
2. 添加第一笔账目
3. 在 [报表页面](/reports) 查看分析
4. 邀请好友加入 [团队协作](/team)

## 技术栈

- React + TypeScript + Vite
- 数据存储：浏览器 localStorage（纯前端无后端）
- 部署：GitHub Actions → GitHub Pages
